# BookSky 📚

BookSky is a simple and interactive book management website built using HTML, CSS, and JavaScript. It allows users to add books with their titles, authors, and descriptions through an easy-to-use interface.

## 🚀 Live Demo

[View BookSky](https://sk-booksky.netlify.app/)

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ✨ Features

- Add new books
- Enter book title, author name, and description
- Display books dynamically on the page
- Delete books when they are no longer needed
- Simple and user-friendly interface

## 📚 What I Learned

- DOM manipulation using JavaScript
- Event handling
- Dynamically creating and removing HTML elements
- Working with forms and user input
- Styling a responsive user interface
